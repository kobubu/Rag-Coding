# Code Memory 0.9.1

GitHub installation fix and the latest repository cleanup for **DeepSeek Harness 0.2.0-rc.2**. Unofficial, independently maintained, and not endorsed by DeepSeek.

## GitHub installation

```bash
dsh plugin --profile web add github:kobubu/Rag-Coding#v0.9.1
```

The tag contains the compiled plugin, CLI entry points, declarations, and static Atlas. GitHub installation no longer depends on a local TypeScript/Vite build or approval of a CM prepare script. Development uses `npm run compile`; CI compares the committed runtime to the build. Older tags still need their release tarball or a source build.

Apache Arrow is now an explicit runtime dependency for LanceDB. This matters in Harness profiles, which disable automatic peer installation. CI checks required peers of direct runtime dependencies so npm's implicit peer installation cannot hide this class of packaging error.

Alternatively, install `dsh-plugin-code-memory-0.9.1.tgz` from this release. Prepare the project's index and pinned local MiniLM model before indexed retrieval; [Harness reference](../DEEPSEEK-PLUGIN.md#github-installation).

## Windows installer

Download **CM-0.9.1-Windows.zip** and **SHA256SUMS.txt**, verify the checksum, and extract the ZIP. Run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_cm.ps1 -ProjectRoot 'C:\path\to\your-project' -Clients harness
```

The ZIP contains the bootstrap, ready npm package, guide, manifest, and checksums. It installs Harness and prepares project data; `-Clients harness,codex,claude` adds project MCP connections. Native-client automatic-context hooks remain a separate manual setup. [Windows guide](../INSTALL-WINDOWS.md).

## Cleanup included

- Removes nine unused functions, an obsolete benchmark type, and an unused import. Active evaluation runners and original A/B evidence remain available.
- Moves React/ReactDOM to development dependencies; static Atlas already includes them. The previous standalone package check measured 8,325,104 bytes excluded from runtime dependencies, including scheduler. This is disk saving, not a new token or speed benchmark.
- Enables unused-local/parameter checks and declares existing direct imports explicitly without upgrading dependency versions.

Retrieval, embeddings, graph routing, prompts, and model settings are unchanged. No new model A/B or savings claim is introduced. [Existing benchmark and limitations](../EFFICIENCY-AB.md).

## Scope

Node.js 24 or 22.19+ within 22.x; pinned Harness; JavaScript/TypeScript; 500 source files and 8 MiB source. Native dependencies follow the package manager's policy. The Windows bootstrap is separate from direct GitHub installation. Models, project indexes, credentials, evaluation workspaces, and developer test artifacts are excluded. A cloud provider still receives selected source context.
