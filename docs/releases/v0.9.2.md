# Code Memory 0.9.2

Reliability update for **DeepSeek Harness 0.2.0-rc.2**. Unofficial community project, independently maintained and not endorsed by DeepSeek.

## Fixes

- Missing or stale indexes, unavailable embeddings, and failed source observation no longer abort an agent step during automatic context retrieval. Harness continues with its normal tools; CM emits a warning and a diagnostic event. Explicit `cm_retrieve_context` calls still return errors. Cancellation still propagates.
- Unwritable diagnostics no longer prevent plugin registration or retrieval. Diagnostics stop after a write failure and retain at most 256 recent events while enabled.
- Whole-file reread pointers are scoped to the agent that received the context. Other agents receive the actual read result. Agent creation, compaction, and disposal clear the associated state; changed files and second reads continue to return source.
- The system guidance now explains what to do when automatic context is unavailable.
- The standard smoke now covers the default compact mode, automatic context, real Harness filesystem observations, invalid budgets, and unload as well as the legacy tools. Regression tests exercise failure recovery, cancellation, agent isolation, and bounded diagnostics.

Retrieval ranking, embedding models, and context budgets are unchanged. This release makes no new token, cost, or speed savings claim.

Validation: 61 automated tests, legacy and compact Harness smoke, and four successful synthetic live-model sessions comparing the old and new plugin. The [protocol and all attempts](../../evaluation/reliability/README.md) distinguish deterministic error-path coverage from the small live healthy-path regression.

## Install or update

```bash
dsh plugin --profile web add github:kobubu/Rag-Coding#v0.9.2
```

For a Windows bootstrap installation, download **CM-0.9.2-Windows.zip** and **SHA256SUMS.txt**, verify and extract the ZIP, then run `install_cm.ps1` with the same project and `-InstallRoot` used previously. This switches the managed launchers to the new release. Restart running clients afterward. See the [Windows guide](../INSTALL-WINDOWS.md).

The tag and tarball include compiled runtime files and Atlas. Node.js 24 or 22.19+ within 22.x is required. Codex/Claude MCP setup and manual hook setup are unchanged.
