# Code Memory 0.9.2

Code Memory is an unofficial local source-context plugin for DeepSeek Harness, independently maintained and not endorsed by DeepSeek.

Version 0.9.2 fixes automatic-context failures interrupting agent steps, diagnostic write failures disabling the plugin, and whole-file read suppression leaking between agents. The standard smoke now exercises the default compact integration through the Harness runtime and filesystem.

Install with `dsh plugin --profile web add github:kobubu/Rag-Coding#v0.9.2`, or use the Windows ZIP with your existing install root. [Release notes](../releases/v0.9.2.md).

This is a reliability release. Previous single-project pilot measurements retain their original limitations; no new general savings claim is made. This announcement draft is not a posted community message.
